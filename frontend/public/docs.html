Section 03

Complete 12-Page Map & Visual Layouts

Every page in the platform serves a specific role in the wedding lifecycle.

01 Landing Page

Route: /

Full marketing portal with Hero banner, 3 Feature showcase cards (Countdown, TikTok Feed, QR Pass), Pricing packages, Live Simulator, and mobile scroll-spy bottom navigation.
02 Celebration Hub (Coming Soon)

Route: /event/[slug]

The core guest destination. Features real-time countdown timer, venue map, personalized QR card pass, Wish Wall with instant submission, song request form, and 1-Click RSVP popup.
03 TikTok Memory Feed

Route: /event/[slug]/feed

Snap-scrolling vertical video reel feed with top navigation tabs (Wishes, Behind the Scenes, Live), double-tap heart animations, slide-up comments drawer, and video upload modal.
04 Live Ceremony Stream

Route: /event/[slug]/live

Full-screen YouTube Live embed with live pulsing broadcast badge, simulated real-time viewer fluctuations, and interactive floating emoji reactions.
05 QR Gate Scanner

Route: /scanner

Field tool for security guards. Scans or looks up invitation codes, validates headcount quotas (e.g., 2 guests), detects duplicate entries, and confirms check-in.
06 Couple Dashboard

Route: /couple/dashboard

The bride & groom's command center. Manage event details, generate custom guest QR invitations with headcount quotas, moderate wishes, approve video reels, and assign field staff.
07 Organizer Dashboard

Route: /organizer/dashboard

Agency management portal. Onboard new weddings, manage credentials for all assigned couples, monitor admin approval statuses, and oversee media moderation across multiple events.
08 System Admin Dashboard

Route: /admin/dashboard

God-mode control room. Approve or reject pending weddings, toggle live broadcast status, manage all system user accounts and passwords, and oversee platform-wide media vaults.

Section 05

1-Click Instant RSVP Mechanism

The RSVP system is engineered for zero friction: the modal automatically appears 5 seconds after page load, requiring only a single tap to record the response immediately.

flowchart TD
    A["Guest Opens /event/[slug]"] --> B["Page loads event details & wish wall"]
    B --> C{"5-Second Timer Fires"}
    C --> D["RSVP Modal Emerges with 3 Choices"]
    
    D --> E["Choice 1: YES 🥂
(Attending Confirmed)"]
    D --> F["Choice 2: MAYBE 🤔
(Undecided)"]
    D --> G["Choice 3: NO 💔
(Declined with Wishes)"]

    E --> H["Instant POST /api/events/[slug]/rsvp"]
    F --> H
    G --> H

    H --> I["Display Checkmark Confirmation Banner"]
    I --> J["Auto-dismiss Modal after 1.8 seconds"]
    J --> K["Update Guest Status in Couple Dashboard"]
🥂 Choice 1: YES
Saves status as ATTENDING. Confirms guest headcount and marks the invitation as confirmed on the couple's live dashboard.
🤔 Choice 2: MAYBE
Saves status as MAYBE. Acknowledges response while allowing the guest to adjust their decision later before final catering lock.
💔 Choice 3: NO
Saves status as DECLINED. Politely records non-attendance while inviting the guest to send their blessings on the Wish Wall.

QR Gate Verification Flow

The gate scanner system ensures venue security by validating unique invitation codes, tracking headcount quotas, and blocking duplicate entry attempts.

    A["Security Staff Opens /scanner"] --> B["Input / Scan QR Code (INV-SD2026-XXX)"]

    C -->|"Valid & Unscanned"| D["🟢 VALID PASS

Section 07

API Route Reference (16+ Endpoints)

Complete specification of all REST endpoints implemented across authentication, public event hubs, organizer tools, and system administration.

Method Endpoint Description Auth Required
POST /api/auth/login Authenticate user with email & password; issue JWT cookie Public
GET /api/auth/me Retrieve profile of the currently logged-in user JWT Token
GET /api/events/[slug] Fetch public wedding event metadata, venue, and playlist Public
PUT /api/events/[slug] Update wedding details (bride/groom names, date, venue, dress code) Couple / Admin
GET /api/events/[slug]/wishes Fetch approved guest blessings for the public Wish Wall Public
POST /api/events/[slug]/wishes Submit a new text or video blessing from a guest Public
GET /api/events/[slug]/media Fetch approved video reel memories for the TikTok feed Public
POST /api/events/[slug]/media Upload a new memory reel (Wishes, BTS, Live clips) Public
POST /api/events/[slug]/rsvp 1-Click instant RSVP submission (Yes / Maybe / No) Public
GET /api/events/[slug]/invitations List all generated guest invitations and scan statuses Couple / Org
POST /api/events/[slug]/invitations Generate a unique invitation QR pass with headcount quota Couple / Org
POST /api/events/[slug]/team Assign a new Live Streamer or Gate Scanner staff member Couple / Org
DELETE /api/events/[slug]/team Remove an assigned field staff member Couple / Org
GET /api/organizer/events Fetch all weddings under organizer agency with credentials Organizer
POST /api/organizer/events Onboard a new wedding event for admin approval Organizer
GET /api/admin/events Master list of all platform weddings with full credentials System Admin
PATCH /api/admin/events Approve/reject weddings, toggle live broadcast status System Admin
GET /api/admin/users List all user accounts across the entire platform System Admin
